COURSE NOTES — GAME SYSTEMS REUSED FROM THE BREAKOUT ASSIGNMENT

  • Same skeleton as Breakout: requestAnimationFrame loop · keyboard state object · AABB collision · score/lives/stage variables · state machine · high-score table. Only the gameplay changed: a paddle-and-ball reflex game became a dig-and-collect tunnel game.
  • Every sprite (miner, GROB, ZIP, boulders, fruit, soil, bedrock) is drawn at runtime with ctx.fillRect on a 16×16 unit grid — no image files, no ripped assets, no emoji.
  • Sound is synthesised with the Web Audio API (oscillators + a noise buffer). The AudioContext is created on the first key press so browsers never block it.
  • Firebase: paste your own values into firebaseConfig at the top of the script. Until then the game detects the placeholders, stays in LOCAL MODE (localStorage) and runs normally. Realtime DB rules for testing: {"rules":{".read":true,".write":true}} — scores are written to the /scores node and read back with orderByChild('score').
